## Project overview

This is a modern, single-page React portfolio built to showcase work, skills, and contact methods. It includes:
- Animated loading screen (SVG + progress)
- Interactive hero with canvas grid and cursor follower
- Sections for About, Projects, Skills, Resume, and Contact
- WhatsApp floating button and contact form (EmailJS-compatible)
- Responsive navbar with a glassy dropdown for small screens
